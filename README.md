# Rafael Oliveira - Personal Website

I’m a technical writer based in Portugal. Before moving into documentation, I spent eight years working in journalism, editing, and editorial coordination.

This website brings together that work and the approach I now bring to technical writing: asking questions, checking the details, and making complex ideas easier to understand.

[Visit the website](https://raffaelpo.github.io/)

## What’s here

- **Home** — an introduction to my work and the experience behind it.
- **Projects** — selected technical articles, data journalism, investigations, and cultural reviews.
- **About** — my professional background, education, and contact details.

## Built with

HTML, CSS, and JavaScript. Hosted on GitHub Pages.

To explore the site locally, clone this repository and open `index.html` in your browser.
